# video-crosscheck

对文字密集型视频做「画面 OCR + 配音转写」**双证据链交叉校验**：找出语音识别错字，以及配音从未念到的幻灯片内容。

给的是可核对的证据清单，不是又一段听起来合理的总结。

## 它解决什么问题

把一条视频转成文字，看起来已经"拿到了内容"。但实际会漏两类东西：

- **语音会听错**：`服务单 → 服务端`、`t s 代理 → TLS 代理`、`前景功能 → 前置功能`；
- **画面根本没念**：表格、字段名、字节示例、流程纪律，UP 主一句都不会说。

前者让你写出**看起来通顺但事实错误**的段落，后者让你**以为讲全了其实缺三分之一**。

本工具把视频拆成两条独立证据再对撞：

| | 配音链（ASR） | 画面链（OCR） |
|---|---|---|
| 强项 | 论述顺序、口语解释、因果 | 表格、字段、数值、字节、流程图 |
| 弱项 | 专有名词、英文缩写、数字 | 小字号、快速切换、图表关系 |

两边弱项互补，所以对撞才看得出单边看不见的错误。

## 快速开始

```bash
pip install rapidocr-onnxruntime imageio-ffmpeg

# 有视频：抽帧 + OCR + 校验一条龙
python scripts/run.py --video video.m4s --transcript transcript.md --outdir out

# 已有抽帧目录：跳过抽帧
python scripts/run.py --frames-dir out/frames --transcript transcript.md --outdir out
```

`transcript.md` 需要带时间轴，格式 `[MM:SS-MM:SS] 正文`（可由 `video-to-note` 之类的转写工具产出）。

产物：

```
out/crosscheck_report.md    # 三栏报告：疑错字 / 配音未覆盖 / 画面其他文本
out/ocr_frames.json         # OCR 缓存，重跑不重复识别
```

算力预期：2 秒抽帧，11 分钟视频约 356 帧，**CPU OCR 约 10 分钟**。

## 报告怎么读

**第一栏「疑似 ASR 错字」** —— 字符级差异，`配音 → 画面` 即修正依据：

```
t=74s  吻合度 0.87
  差异：单 → 端
  配音整句：又会把操作数据传给服务单，启动服务单会按要求处理对应的操作...
```

**第二栏「配音未覆盖的幻灯片内容」** —— 只出现在画面上、配音没念的文字。含噪声，需人工筛。

**第三栏「画面其他文本」** —— 游戏内文本、图表标注、聊天截图。单独列出是为了说明它们没被误判成字幕。

## 为什么这样设计（关键约束）

这些阈值和方法不是拍脑袋定的，每一条都对应一次失败：

1. **比对必须用最长公共子串 + 滑窗对齐，不能用整体 `ratio`。**
   一句字幕比整段 ASR（一段常含两三句），比值天然偏低，实测报出 110/180 假阳性。
2. **"高相似"里才藏着最该修的错误。**
   一个字的错，20 字句子相似度仍有 `19/20 = 0.95`。用低阈值筛"不一致"，方向是反的。
3. **字幕带不能用固定像素阈值。**
   视频中途可能出现全屏截图、AI 对话窗口，底部区域会混入大量非字幕文本，
   必须叠加「位置 + 长度上限 + 中文占比」三重过滤。
4. **帧聚类用集合 Jaccard，不用序列相似度。**
   同一页在相邻帧里 OCR 行序不稳定，按顺序比会反复误判成新页。
5. **单行文字要按出现频率过滤。**
   OCR 噪声只闪一两帧，真实文本会在本页多数帧出现。

三级分类让报告量级可控：

| 吻合度 | 归类 | 处理 |
|---|---|---|
| ≥ 0.98 | 一致 | 忽略 |
| 0.80 – 0.98 | **疑似错字** | 逐条人工确认 |
| < 0.80 | 画面其他文本 | 另列 |

## 边界

- **不写笔记**。只产出差异报告，成稿的取舍和结构由调用方决定。
- **不做纠错闭环**。报告只列证据，是否采纳由人判断。
- **OCR 表格的列顺序不可信**。它是按视觉行输出的，跨列表格会被打散重排。
  涉及关键表格，**必须抽帧人眼重排**，不要拿 OCR 直出当成品表格用。
- **快速切换的帧会漏**。2 秒是甜点值；一页存在不足 2 秒会丢。
- **不绕过平台权限**。高清流、会员内容、登录可见内容需要用户自己的凭据。

## 什么时候不该用

纯 Vlog、纯实拍、画面只有 B-roll 的视频——OCR 拿不到文字，白烧十分钟。

一句话判断：**这视频的画面上有没有你转写稿里没有的字？** 有就值得。

## 作为 AI Skill 使用

把本仓库根目录的 `SKILL.md` 放进 agent 的技能目录即可，例如：

```
C:\Users\<用户名>\.agents\skills\video-crosscheck\
```

配合转写技能使用：先用转写技能拿到带时间轴的文字稿，再用本技能做校验。
